title: "TypeScript SDK"
---

`@haip/sdk` provides ordinary HTTP creation, status, cancellation, event cursors, audit export, exclusive claims, admission and outcome reporting. It does not expose human confirmation as a machine convenience method.

```ts
import { HAIPClient } from '@haip/sdk';
const client = new HAIPClient('https://review.example', producerToken);
const request = await client.create(input, stableIdempotencyKey);
const status = await client.status(request.request.id);
const page = await client.events(savedCursor);
// Process page.items durably, then save page.next.
```

`verifyExecutionAuthority` checks trusted signatures, immutable request/response/material commitments, purpose/profile, receipt/claim/admission identity, fresh nonce, checkpoint proof and timing. Supply trust independently and implement the independent anchor-acceptance callback. Included manifests and supplied acceptance objects are not self-authenticating trust.

Record monotonic and wall-clock time around admission. Thirty seconds is clock-health tolerance, not extra validity. Keep the returned deadline check at the launch fence and first covered mutation. Fresh status never moves the original dispatch deadline.

`verifyWebhook` checks the envelope and nested signed event, exact identity and a five-minute replay window. `PostgresWebhookInbox` commits deduplication and a status-refresh queue before acknowledgement. Its queue contains advisory revisions; a consumer fetches current status. No callback launches work.

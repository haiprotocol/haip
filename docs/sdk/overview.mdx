---
title: 'TypeScript SDK'
description: 'Use the HAIP 2 public HTTP API without an agent framework.'
---

`@haip/sdk` is the TypeScript client for **2.0.0-draft.2**. It depends on the independent protocol package and does not need Plasm or an agent framework. The draft packages are built from this workspace; do not assume the public `latest` npm tag contains HAIP 2.

```sh
npm ci
npm run build
```

A producer client uses an exact HTTPS origin and a separately provisioned bearer credential:

```ts
import { HAIPClient } from '@haip/sdk';

const client = new HAIPClient('https://review.example', producerToken);
const accepted = await client.create(requestInput, stableIdempotencyKey);
const current = await client.status(accepted.request.id);
```

The variables represent your configured credential, validated `RequestInput` and a key kept stable for that logical creation. The [HTTP example](/examples/review) supplies a concrete local request and fixture credentials.

The SDK exposes creation, status, cancellation, events and audit export, plus execution claim/admission/outcome methods. It deliberately has no machine convenience method for human confirmation.

Use the [method reference](/sdk/api-reference), [credential guide](/sdk/authentication) and [error handling](/sdk/error-handling) for ordinary review. Executors must additionally follow [authority verification](/sdk/execution). Webhook consumers use the separate [verification and persistence helpers](/sdk/webhooks).

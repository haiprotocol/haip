---
title: "Errors and retries"
---

Errors return JSON with a stable `error` code. The service does not disclose foreign resource existence: an inaccessible request or publisher-owned bundle returns not found.

| HTTP status | Meaning |
|---|---|
| 400 / 413 / 415 | Invalid, too large or unsupported request encoding |
| 401 / 403 / 404 | Authentication, permission or inaccessible resource |
| 409 | State, identity, candidate or idempotency conflict |
| 410 | Retained material or idempotent result has expired |
| 422 | Unsupported revision, profile, renderer or mode |
| 429 | Captured quota or operational limit |
| 503 | Required authority, storage or identity unavailable |

Retry transient transport failures with the same idempotency key. Do not treat 503 as permission to bypass review, anchoring or identity checks. Expired grants and consumed occurrences never become available because a retry waited longer.

After a possible launch, preserve the launch fence and report uncertainty. Operators need reasons and evidence to reconcile. A new attempt requires a newly linked occurrence and fresh approval; it must not replay the original whole plan.

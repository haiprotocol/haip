---
title: "Independent HTTP examples"
---

The examples use HAIP credentials and public endpoints without Plasm or another agent framework.

`examples/http/review.mjs` creates a structured-choice review from `review.json`. The optional `choice-app.js` is independently bundled with the exact supported MCP pins. Register it with `register-app.mjs` using the publisher credential, then reference its bundle ID with the producer credential. The App proposes a response; only trusted host confirmation records the decision.

`examples/http/counter.ts` exports `runCounter`, a deliberately bounded one-counter executor. It verifies signed authority and independent anchor acceptance, records original evidence, persists a launch fence, checks the monotonic deadline at the first mutation and writes one local effect. It reports the result separately. A lost outcome-report connection can be retried without another effect. A fence without a completed result remains uncertain.

The tests demonstrate ordinary browser confirmation, signed decimal response retrieval, events, one effect, refusal of invalid authority and recovery after a lost report. These are fixed fixtures, not a general runtime or production-effect integration.

Run `npm run check`, `npm run test:cross-language` and `npm run example:app`. The research index records actual runs and the limits of their evidence.

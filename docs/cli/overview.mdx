---
title: 'Command-line client'
description: 'Create reviews and inspect their results through the public HTTP API.'
---

The HAIP 2 CLI is built from this workspace and calls the same scoped HTTP API as other producers. The public npm `latest` tag is not assumed to contain this draft.

```sh
npm ci
npm run build
node haip-cli/dist/index.js help
```

Set `HAIP_URL` to an exact HTTPS origin and `HAIP_TOKEN` to a producer credential, then submit a validated request file with a stable idempotency key:

```sh
node haip-cli/dist/index.js create examples/http/review.json review-demo-1
node haip-cli/dist/index.js status REQUEST_ID
```

The person follows the returned review link and confirms through the authenticated browser. The CLI cannot approve a request. Its commands cover creation, status, cancellation, events, audit export and generic signature verification.

Use the [command reference](/cli/commands), [configuration guide](/cli/configuration) and [complete local example](/examples/using-cli). HAIP 1 chat, send and streaming commands are unsupported; their old guidance is retained in the [archive](/archive/v1/index).

---
title: "HAIP — Human-Agent Interaction Protocol"
---

HAIP 2 is an independent draft protocol for portable human review and verifiable execution authorisation. Producers supply immutable material, an optional MCP App and a response schema. Authenticated humans confirm exact responses in a trusted host.

The reference implementation provides a native inbox, PostgreSQL service, TypeScript SDK and CLI. Review works through ordinary HTTP without Plasm or an agent framework. Execution uses separate purpose-bound grants, exclusive claims and fresh admission.

**Status: draft implementation, not a full HAIP 2 release.** Plasm delayed approval is not yet available. See the repository implementation ledger for tested behaviour and remaining gates.

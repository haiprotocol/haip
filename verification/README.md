# Verification packages

## `native-isolate/`

Quint model and review docs for the **native HAIP Agent UI** extension and the HAIP 2
approval→effect safety spine.

This is a new protocol extension. No MCP compatibility shims.

[PR #6](https://github.com/haiprotocol/haip/pull/6) proposes applying the profile to
the HAIP 2 Host/View implementation (`haip/ui.*`, `agent_ui: "1"`,
`haip.agent-ui: "1"`).
